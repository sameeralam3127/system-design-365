# Glossary

Terms used across the case studies, defined precisely enough to be useful in an
interview. Entries are added as the case studies that need them are written,
rather than up front — a glossary written in advance tends to define the terms
the author already knows.

graceful degradation

Kubernetes: QoS class · eviction · taint and toleration · topology spread ·
